Projet phare · Stage ACSI 2026

IAM ACSI — Plateforme d'identité et d'accès 100 % locale

Concepteur et développeur

Plateforme de gestion des identités et des accès développée pour l'ACSI afin de remplacer Keycloak : toutes les données restent sur les serveurs de l'organisation. Une seule connexion donne accès à l'ensemble des applications métier.

  • Authentification unique (SSO) et fournisseur OAuth 2.0 / OpenID Connect (code + PKCE, jetons RS256)
  • Double authentification par code à usage unique, verrouillage des comptes, politique de mots de passe
  • Rôles à trois niveaux (Administrateur, Agent, Utilisateur simple) et permissions par application
  • Assistant d'ajout d'application : détection automatique des rôles d'une application Laravel
  • Console d'administration : utilisateurs, import CSV, organisations, sessions, journal d'audit, API REST
PHP 8 MySQL / MariaDB OAuth 2.0 OpenID Connect Apache Python
